# Privacy and Content Boundary

This repository is a showcase, not a vault export.

## Included

- Architecture documentation
- Agent routing patterns
- Redacted/synthetic sample notes
- Metadata schema
- Validation script
- Portfolio-level explanation of the system

## Excluded

- raw PDFs, EPUBs, books, papers, and articles
- real source summaries from third-party works
- personal notes
- health, finance, career, family, or private project details
- full Obsidian vault export
- exact private corpus contents

## Why this boundary exists

The private vault is built from a mixture of personal notes, licensed/purchased sources, public papers, project context, and private reasoning. Publishing it wholesale would be inappropriate.

The interesting portfolio artifact is the system design:

- how sources are routed
- how agents know what to read
- how maturity is represented
- how private corpus knowledge is turned into safer agent behavior

That is what this repo shows.

## Validation posture

The showcase includes a validation script that fails if obvious private-vault patterns or raw-source directories are introduced.

It is not a perfect secret scanner. It is a guardrail.

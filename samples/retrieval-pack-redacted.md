# Redacted Retrieval Pack Example

## Default Route

1. Classify the task.
2. Open the relevant operating card.
3. Open the task-specific playbook.
4. Open source notes only when evidence or caveats are required.
5. Validate against live authoritative sources before acting.

## Read Paths

| Task | Read |
|---|---|
| Example code change | operating card → project manifest → live repo |
| Example evidence question | retrieval pack → source summary → fidelity gate |
| Example strategy question | playbook → concept cards → measurement route |

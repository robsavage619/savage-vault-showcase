# Redacted Source Summary Example

## Summary

This is a synthetic sample. It shows how a source-summary note is structured without exposing real source content.

## Agent Rules

- State what the source can and cannot support.
- Keep approved use and prohibited use explicit.
- Route to live authoritative sources when current state matters.

## Failure Modes

- Treating a note as proof of live state.
- Using a framework outside its evidence lane.
- Omitting uncertainty.
